# Yichuan Zhang

Academic website for Yichuan Zhang at https://yczhang.org/.

- `index.html` holds the shared page layout. `sections/` holds the Home, Research, and Teaching content.
- `css/`, `fonts/`, and `fig/` hold styles, fonts, and the portrait.
- `.github/workflows/deploy.yml` builds and deploys the site to GitHub Pages when `master` changes.

Run `sh scripts/build.sh` and serve `_site/` with a local static HTTP server to preview the site.
